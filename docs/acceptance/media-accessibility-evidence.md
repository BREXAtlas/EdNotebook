# Media accessibility and evidence acceptance

Run this gate on staging with the Digital Literacy pilot course and the existing professor/student test accounts.

## Professor

1. Open **Course Builder → Media & resources**.
2. Add a YouTube video to a specific lesson.
3. Leave accessibility support at **Choose caption or transcript support** and confirm publication pauses with an accessibility-review message.
4. Verify the source captions or add a reviewed transcript, then publish the next course version.
5. Add a replacement for that video, select the earlier media version, and enter a change note.
6. Confirm the library shows media versions 1 and 2, with version 1 retained as replaced and version 2 awaiting the next publish.
7. Open viewing evidence and confirm it shows aggregate started/completed/transcript/caption counts without student IP, device, or second-by-second history.

## Student

1. Open the published lesson and confirm the video stays inside EdNotebook.
2. Choose **Play with captions** and verify captions start in the provider player.
3. Pause, resume, and finish the media; confirm the saved viewing-position label advances.
4. Open the searchable transcript and copy it.
5. Confirm the page says viewing evidence is not proof of attention or learning.

## Version boundary

1. Before the professor republishes, confirm the student still receives the earlier media.
2. Publish the replacement as the next course version.
3. Confirm new student activity begins against the replacement while the earlier version's evidence remains historical.
